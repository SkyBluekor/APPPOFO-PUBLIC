## 실제 얼굴 인식 장면

![카메라가 얼굴을 인식하고 명함을 화면에 보여주는 실제 AppPoFo 실행 화면](real-face-recognition.png)

**파일:** [real-face-recognition.png](real-face-recognition.png)

원본 Private 프로젝트의 `Docs/Images/screenshots/recognition.png`에서 가져왔습니다. 2026년 10월 28일 Samsung Galaxy Tab A7(SM-T500)에서 실행 중인 앱을 촬영한 화면으로, 카메라에 얼굴을 비추자 등록된 사람의 이름과 기술이 담긴 명함이 나타난 장면입니다.

- 얼굴 사진은 **픽셀 모자이크**하여 공개용으로 처리했습니다. UI·인식 상자·명함 문구는 그대로 유지했습니다.
- 원본 저장소의 촬영 기록은 해당 공개용 화면의 사용 승인을 명시합니다.
- **내 기기(로컬) 모드**에서 촬영했습니다. 서버 모드 작동 화면은 아닙니다.
- 촬영 이후 별도로 만든 공개 소스를 다시 Android에 설치해 찍은 사진은 아닙니다.
- 이 사진 한 장이 모든 얼굴과 기기에 대한 인식 성능을 보장하지는 않습니다.
