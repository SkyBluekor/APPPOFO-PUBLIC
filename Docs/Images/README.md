# AppPoFo 실제 화면 캡처

[← 프로젝트 소개](../../README.md)

2026-10-29, **Unity 6000.5.4f1 Play Mode**에서 실제 앱의 Game 창을 540×960으로 캡처한 화면입니다. 새로 만든 **가상 데모 프로필**을 사용했습니다. 그래픽으로 새로 그린 시안이나 Android 실기기 촬영 화면이 아닙니다.

| 파일 | 무엇을 보여주나요? |
|---|---|
| [01-welcome.png](01-welcome.png) | 로컬/서버 시작 화면 |
| [02-onboarding-skills.png](02-onboarding-skills.png) | 프로필에서 기술 항목을 등록하는 화면 |
| [03-business-card.png](03-business-card.png) | SQLite에 저장된 데모 프로필의 명함 화면 |
| [04-profile-detail.png](04-profile-detail.png) | 저장한 프로필 상세 화면 |

**주의:** 이 네 장의 이미지만으로 물리 카메라의 실시간 얼굴 인식 시연이 검증되지는 않습니다. 실제 모델 추론과 합성 얼굴 fixture를 통한 로컬 저장·인식·명함 연결은 별도 검증했습니다. 실물 얼굴 사진·실사용자 연락처·운영 DB는 포함하지 않았습니다.

검증 기록과 이미지 해시는 [CLONE_REPRODUCIBILITY.json](../../Audit/CLONE_REPRODUCIBILITY.json)에 있습니다. 일부 기술 아이콘은 [별도 권리 검토](../UI_RIGHTS_REVIEW.md) 대상입니다.
