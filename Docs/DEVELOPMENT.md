# AppPoFo를 만들면서 해결한 문제들

[← 프로젝트 소개](../README.md)

앱이 어떻게 만들어졌는지 궁금한 사람을 위해, 어려운 코드보다 **무슨 문제가 있었고 어떻게 고쳤는지** 먼저 설명합니다.

## 1. 얼굴을 찾는 것과 사람을 알아보는 것은 다릅니다

**상황:** 카메라가 얼굴을 찾더라도, 그 얼굴이 누구의 것인지 모르면 명함을 보여줄 수 없습니다.

**만든 기능:** 얼굴에서 특징을 추출하고, 등록해 둔 얼굴 특징들과 비교한 뒤 가장 비슷한 사람의 프로필을 찾아 명함으로 보여줍니다. 다른 사람으로 잘못 판단하지 않도록 비교 기준도 적용했습니다.

**확인한 결과:** 원본 앱의 Samsung Galaxy Tab A7에서 실제 얼굴을 인식하고 이름이 적힌 명함을 띄운 화면을 촬영했습니다. [실제 사진](Images/real-face-recognition.png)

개발자 참고: [특징 계산](../Assets/AppPofo/Presentation/FaceRegistration/Embedding/SFaceRecognizer.cs) · [비교](../Assets/AppPofo/Presentation/FaceRecognition/Matching/FaceRecognitionMatcher.cs) · [명함 표시](../Assets/AppPofo/Presentation/Screens/BusinessCardPanelController.cs)

## 2. 처음 카메라를 켰을 때 화면이 멈추는 문제

**상황:** 개발 중 사용한 Galaxy Tab A7에서 얼굴 인식 화면에 들어가자 처음에 화면이 수십 초간 멈추는 문제가 있었습니다.

**개선:** 카메라가 화면을 보여주는 일과 얼굴 인식을 준비하는 일을 분리했습니다. 기기에 맞는 AI 실행 방식도 검토하고 무거운 작업이 화면 표시를 길게 가로막지 않도록 조정했습니다.

**확인:** 원본 개발 과정에서 약 26초의 초기 정지 사례가 있었고, 개선 이후 별도 로컬 측정 한 번에서 **첫 명함 생성 1.44초**를 확인했습니다. 조건이 다른 측정이므로 단순히 '26초에서 1.44초로 빨라졌다'는 비교로 읽으면 안 됩니다. 모든 기기에서 1.44초라는 뜻도 아닙니다.

[실제 관련 코드](../Assets/AppPofo/Presentation/FaceRecognition/FaceRecognitionCamera.cs)

## 3. 얼굴을 잠깐 놓치면 명함이 깜빡이는 문제

**상황:** 사람이 살짝 움직여 한 번 인식이 실패할 때마다 명함이 바로 사라지는 현상이 있었습니다.

**개선:** 짧은 인식 실패가 있어도 기존 명함을 잠시 유지하도록 처리했습니다. 계속 얼굴이 보이지 않거나 카메라를 닫으면 명함을 정리합니다.

**확인:** 원본 프로젝트의 테스트와 개발 기록에서 인식 중 잠깐의 실패 상황을 다뤘습니다. 실제 체감은 카메라와 조명 환경에 따라 달라질 수 있습니다.

## 4. 서버가 사람을 찾았는데 명함 사진이 안 나오는 문제

**상황:** 서버의 얼굴 검색은 성공했지만 사진이 담긴 명함 정보가 앱에 제대로 전달되지 않는 문제가 있었습니다.

**개선:** 사진이 추가되면서 커진 데이터를 받을 수 있도록 처리 범위를 수정하고 같은 유형의 오류를 잡는 테스트를 추가했습니다.

**확인:** 원본 Android 실기기에서 사진을 포함한 명함 표시가 확인된 개발 기록이 있습니다. 이 화면은 공개 저장소의 새 로컬 실행 검증과 구별합니다.

## 5. 다른 사람이 내려받아 실행할 수 있게 만드는 일

**상황:** 개발자 PC에만 설치된 모델 파일이나 개인 데이터가 있어야 실행된다면 공개 포트폴리오라고 보기 어렵습니다.

**조치:** 개인 데이터와 비밀키는 제외하고, 공개 가능한 소스와 설정을 남겼습니다. 필요한 외부 도구와 AI 모델은 정해진 출처에서 따로 설치하도록 구성했습니다.

**확인:** 공개 소스를 독립된 폴더에 복원해 Unity 실행, 데모 프로필 저장, 얼굴 특징 비교와 명함 화면 표시를 검증한 기록이 있습니다. 이 검증에서는 실제 카메라 대신 합성 테스트 데이터를 사용했습니다.

## 사용한 기술을 조금 더 알고 싶다면

얼굴을 찾는 YuNet과 얼굴의 특징을 만드는 SFace는 **기존에 학습된 AI 모델**입니다. AppPoFo의 개발 포인트는 이 모델들을 Unity 앱과 연결하고, 얼굴 등록·비교·저장·명함 UI를 하나의 사용 흐름으로 만든 부분입니다. 직접 제작한 응용 기능과 가져다 쓴 모델을 구분해서 설명합니다.

[기존 테스트 결과](../Audit/TEST_RESULTS.json)에서는 Unity 자동 테스트 EditMode 531개·PlayMode 53개, 서버 테스트 85개의 통과 기록을 확인할 수 있습니다. 다만 **테스트 개수는 얼굴 인식 정확도나 실제 사용자 수를 뜻하지 않습니다.**
